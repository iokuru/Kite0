# Pre-built Browser Extension Packages

Pre-compiled, ready-to-load distribution packages for Kite0 v0.1.1. No build tools or terminals required.

---

## Direct Downloads

- **[kiteo-chrome-v0.1.1.zip](kiteo-chrome-v0.1.1.zip)** — For Google Chrome, Brave, Microsoft Edge, Opera, and Vivaldi (Chromium MV3).
- **[kiteo-firefox-v0.1.1.zip](kiteo-firefox-v0.1.1.zip)** — For Mozilla Firefox and LibreWolf (Gecko MV3).

---

## 3-Step Installation (No Terminal Required)

### Chromium Browsers (Chrome / Brave / Edge / Opera)
1. Download **`kiteo-chrome-v0.1.1.zip`** above and extract it on your computer.
2. In your browser address bar, go to `chrome://extensions/` (or `edge://extensions/` on Edge).
3. Turn on **Developer mode** (top-right switch), click **Load unpacked**, and select the extracted folder.

### Firefox
1. Download **`kiteo-firefox-v0.1.1.zip`** above and extract it.
2. In Firefox address bar, go to `about:debugging#/runtime/this-firefox`.
3. Click **Load Temporary Add-on...** and select `manifest.json` inside the extracted folder.
